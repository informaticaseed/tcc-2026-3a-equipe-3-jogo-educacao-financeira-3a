1. O que é uma Issue e para que serve no desenvolvimento de software?
é uma forma simples de  manter o projeto em ordem, garantindo que nada se perca no caminho. Ela serve para registrar tudo sobre o projeto ou possiveis melhorias que precisam ser feitas.

2. O que é um Pull Request e por que ele é importante?
O PULL Request é como se fosse um pedido de alteração no projeto onde os membros podem ver quais alterações foram feitas e aprova-las.

3. O que é separação de camadas no código?
Explique a diferença entre app.py e repositorio.py e por que isso importa.
Separação de camadas no código é basicamente dividir responsabilidades para deixar o sistema mais organizado e fácil de manter.
app.py é porta de entrada que tem como objetivo receber requisições, chamar funções e devolver respostas.
repositorio.py é para os membros acessarem e poderem manipular dados.
